# Ruptura - GitHub Release
O index carrega automaticamente a ultima Release do repositorio otaviofelisberto0-creator/Ruptura.

Assets obrigatorios em cada Release:
- painel_autonomia.json
- reserva_sc.json
- reserva_pr.json
- controle_equipe.json
- metadata.json

Atualizacao:
1. Pagina Analista: carregar 4 arquivos e Validar analise.
2. Clicar Converter e baixar JSONs.
3. Colocar os 5 JSONs na pasta release-data do repositorio e fazer commit.
4. Actions > Publicar bases da Release > Run workflow.
5. Informar uma tag nova (ex.: dados-2026-11-18-1445).
6. Ao recarregar o dashboard, a nova ultima Release vira a fonte oficial.
